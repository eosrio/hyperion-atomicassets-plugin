# AtomicMarket marketplace list source controls

The route `/atomicmarket/v1/marketplaces` reads all records of the existing marketplace kind through the optional SDK complete-kind host. It declares the existing projection's `readAttempts`, `responseRecords` and `responseBytes` as the required offer. The host and adapter negotiate those totals; no public pagination, ordering, filter or count is exposed. A missing host or invalid, foreign, or mismatched row fails the request. The existing reducer keeps the first creation block and time across replacements.

`tests/marketplace-list.test.mjs` runs the actual pinned atomicassets-api 2.7.0 HTTP callback and its SQL invocation with a scripted database boundary and compares empty and multiple rows against plugin HTTP. It retains both arrays, compares membership and fields without assuming SQL order, and exercises ignored query and POST body inputs, GET, POST and HEAD, and invalid row refusals. `tests/marketplace-id.test.mjs` independently compares the actual original replacement processor. These controls are not physical PostgreSQL/MongoDB comparison or a managed host acceptance. Actual adapter exhaustion, overbudget refusal, cache-enabled behavior and full AtomicAssets/AtomicMarket 2.7.0 parity remain release qualification work.
